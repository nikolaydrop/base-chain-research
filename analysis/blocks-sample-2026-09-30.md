# Block sample analysis: 100 Base blocks

Run date: 2026-09-30
Data: `data/blocks.csv` (generated by `scripts/export_blocks.py`)
Range: blocks 51974687 to 51974786 (about 3.3 minutes)

| Metric | Value |
|---|---|
| Average block interval | 2.00 s |
| Transactions in total | 20,312 |
| Transactions per block | 203 average (min 135, max 332) |
| Throughput | about 103 transactions per second |
| Gas used vs. limit | 11% average, 18% maximum |
| Base fee | 5,000,000 wei (0.005 gwei) in every block |

## Observations
- Blocks were produced at an exact 2 second cadence.
- Blocks were far from full, so there was no fee pressure and the base fee stayed at its minimum.
- Throughput of about 100 tx/s in a quiet moment is many times higher than typical Ethereum L1 throughput.

## Limitations
- This is a single short sample from one moment, not a daily average.
- The numbers count all transactions, including automated ones.
