# OP Stack and the Superchain

- The OP Stack is an open-source set of software components for building L2 chains. Base is built on it.
- The Superchain is a network of OP Stack chains that share the same technology and are designed to communicate with each other.
- Base was launched by Coinbase in 2023 and follows the OP Stack upgrade path.
